Un día con AGENTIC

Todo ocurre
solo.

Cinco daemons trabajan en paralelo, 24 horas al día, sin intervención manual. Desde que duermes hasta que cierras el portátil.

03:00 — De noche
El briefing se prepara
GitHub Actions lanza el script a las 03:03. Lee tu calendario, busca en el RAG el historial de cada cliente, y genera el briefing con GPT-4o.
08:00 — Mañana
En tu correo
Abres Gmail y el briefing ya está ahí. Perfil del contacto, historial de reuniones previas, propuestas enviadas y puntos clave a tocar.
10:00 — Reunión
Preparado al 100%
Sabes exactamente qué se habló en la última reunión, qué propuesta enviaste y qué preguntar. Todo buscable en segundos con el RAG.
11:30 — Después
Follow-up automático
Granola transcribe la reunión. El watcher la detecta, extrae los compromisos con GPT-4o, genera un PDF branded y crea el borrador del email.
Continuo — Siempre
Todo respaldado
Cada documento, transcript y perfil se sincroniza y versiona automáticamente. Git sync cada 15 min. Nightly backup en la nube. Sin tocar nada.
22:00 — Noche
Conocimiento consolidado
La KB consolidation promueve los hechos estables del día a la base de conocimiento permanente. El sistema aprende solo, sin que hagas nada.

Cómo está construido

WAT framework.

Tres capas que se coordinan sin rozamiento. Las instrucciones definen el proceso. El agente razona. Las herramientas ejecutan.

W
Workflows
SOPs en markdown que definen el objetivo, los inputs, las herramientas, los outputs esperados y los casos límite. El proceso, documentado y reproducible.
“Para cada reunión comercial: busca RAG → construye briefing → genera HTML → envía draft”
A
Agent
Claude lee la tarea, elige el workflow correcto, consulta el contexto existente, usa las herramientas en el orden adecuado y produce el output en el lugar correcto.
“Joan menciona Vueling → consulto RAG → leo propuestas anteriores → preparo briefing”
T
Tools
Scripts, parsers, builders y MCPs que ejecutan tareas concretas de forma determinista. Cada herramienta hace una cosa y la hace siempre igual.
sync_granola.py · workspace_watcher.py · generate_document.py · mcp_server v1.6
Las piezas

Infraestructura
elegida.

Cada componente hace exactamente lo que tiene que hacer. Elegida por funcionar, no por ser moderna. Sin redundancias.

OpenAI Vector Store
1700+ documentos indexados: propuestas, transcripciones, briefings e imágenes procesadas con Vision API. Búsqueda semántica con filtros.
Granola MCP
Transcripción automática de reuniones. El daemon sincroniza nuevas transcripciones al vector store en tiempo real.
Gmail + Calendar MCP
Acceso directo al calendario y Gmail para detectar reuniones y crear borradores de briefings y follow-ups.
GitHub Actions
Briefing diario desde la nube a las 04:03 CET. Deploy de status page. Nightly sync. KB consolidation. Todo funciona aunque el Mac esté apagado.
WeasyPrint + LaunchAgents
HTML → PDF con calidad de imprenta. 5 daemons macOS permanentes: workspace, granola, healthcheck, git-sync, zoho.
Claude + GPT-4o
Claude (agente principal, razonamiento) + GPT-4o (briefings cloud, extracción de compromisos). Cada modelo donde rinde mejor.

Seguridad

Los datos
están seguros.

El sistema maneja información confidencial de clientes. Diseñado desde el principio para que esos datos nunca queden expuestos.

Repositorio privado
Todo el código y la configuración en un repo GitHub privado. Acceso por invitación.
Credenciales cifradas
Ningún secreto en el código. API keys y tokens en GitHub Actions Secrets — cifrado AES-256.
Vector store aislado
1700+ documentos en un vector store privado de OpenAI. Solo accesible con la clave API del workspace.
Trazabilidad completa
Cada cambio registrado en git con timestamp y autoría. Compliance log (JSONL) para auditoría completa.
