Cómo está construido

WAT framework.

Tres capas que se coordinan sin rozamiento: las instrucciones definen el proceso, el agente razona y decide, las herramientas ejecutan con precisión.

W

Workflows

SOPs en markdown que definen el objetivo, los inputs, las herramientas, los outputs esperados y los casos límite. El proceso, documentado y reproducible.

"Para cada reunión comercial: busca RAG → construye briefing → genera HTML → envía draft"
A

Agent

Claude lee la tarea, elige el workflow correcto, consulta el contexto existente, usa las herramientas en el orden adecuado y produce el output en el lugar correcto.

"Joan menciona una reunión con Vueling → consulto RAG → leo propuestas anteriores → preparo briefing"
T

Tools

Scripts, parsers, builders y MCPs que ejecutan tareas concretas de forma determinista. Cada herramienta hace una cosa y la hace siempre igual.

register-document.sh · sync_granola.py · workspace_watcher.py · mcp_server_standalone.py
Qué hace

Automatizado
para ti.

Cada capacidad elimina una tarea que antes consumía tiempo. El sistema hace el trabajo preparatorio. Tú haces el trabajo de relación.

  • Llegas a cada reunión con el contexto completo
  • Conoces a cada cliente mejor que él mismo
  • Propuestas generadas en minutos, no en horas
  • El follow-up se redacta solo tras cada reunión
  • Lee texto e imágenes: presentaciones, organigramas y logos procesados con IA visual e indexados como cualquier documento
  • El conocimiento se consolida solo, semana a semana
  • El estado del sistema, visible desde cualquier lugar

"El sistema no te reemplaza. Te libera para hacer lo que solo tú puedes hacer: construir la relación, cerrar la propuesta, entender al cliente."

Las piezas que lo mueven

Infraestructura elegida por funcionar, no por ser moderna. Cada componente hace exactamente lo que tiene que hacer, sin redundancias.

1700+ docs indexados

OpenAI Vector Store
Base de conocimiento vectorial con 1700+ documentos: propuestas, transcripciones, briefings e imágenes procesadas con Vision API. Búsqueda semántica con filtros por cliente, categoría y fecha.
Granola MCP
Transcripción automática de reuniones. El daemon granola_watcher sincroniza nuevas transcripciones al vector store en tiempo real, sin intervención manual.
Gmail + Google Calendar MCP
Acceso directo al calendario para detectar reuniones del día y a Gmail para crear borradores de briefings y follow-ups. Sin abrir ninguna aplicación.
GitHub Actions
El briefing diario se genera y envía desde la nube a las 04:03 CET, incluso con el Mac apagado. Backup automático de cada briefing en el repositorio.
WeasyPrint · LaunchAgents macOS
Propuestas HTML → PDF con calidad de imprenta. Cinco daemons (workspace_watcher, granola_watcher, healthcheck, git-sync, zoho-sync) corriendo permanentemente — se reinician solos si fallan.

Seguridad y privacidad
Los datos
están seguros.

El sistema maneja información confidencial de clientes. Está diseñado desde el principio para que esos datos nunca queden expuestos.

Repositorio privado
Todo el código y la configuración viven en un repositorio GitHub privado. Acceso restringido por invitación. Nadie externo puede ver nada.
Credenciales cifradas
Ningún secreto en el código. Todas las API keys, contraseñas y tokens están en GitHub Actions Secrets — cifrado AES-256, gestionado por GitHub.
Base de conocimiento aislada
Los 1973+ documentos se indexan en un vector store privado de OpenAI, accesible únicamente con la clave API del workspace. Ningún dato es público ni compartido.
Trazabilidad completa
Cada cambio en el sistema queda registrado en git con timestamp y autoría. Hay un audit trail completo de qué se hizo, cuándo y por qué.
